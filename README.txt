CARRY SMART — SCHOOL BAG LOAD & POSTURE WEBSITE

Files
- index.html: website structure and content
- style.css: responsive styling, illustrations, layout, print styles
- script.js: interactive tab navigation, packing checklist, and physics calculator

How to use
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. The website works as a static site. No build process or server is required.
4. To publish, upload the folder contents to a static hosting service such as Netlify or GitHub Pages.

Notes
- Most illustrations are original inline SVG/CSS, so no image downloads are required.
- Google Fonts are loaded online; system fonts are used as fallback if offline.
- Survey findings are based on the provided report. The site uses 26 respondents as in the results and updated scope; the source report's methodology also mentions 25, so reconcile that discrepancy before final submission.
- The interactive work calculator uses example values only and does not estimate respondents' actual bag weights or spinal loading.
